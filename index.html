Hermes Agent Integration

Automate classifieds search and monitoring on Kleinanzeigen Germany.

A dual-mode tool for Hermes Agent. Execute structured keyword searches with 5-digit postal code radii and price filters, or run SQLite-backed polling cron jobs with Telegram-ready notifications.

Installation & Setup

Choose between the primary Hermes Plugin distribution or the fallback standalone skill.

Primary & Recommended

Native Hermes Plugin

Recommended for all standard Hermes Agent setups. Dependencies are automatically provisioned inside Hermes's isolated virtualenv, and tools are exposed directly to the model as native function calls.

Installation Command 
$ hermes plugins install clockwork-dev/hermes-kleinanzeigen --enable --yes-deps
Verification Command 
$ hermes plugins doctor kleinanzeigen
  • Zero virtualenv management: Hermes manages requests, beautifulsoup4, and fake-useragent automatically.
  • Native tool calling: Zero subprocess and shell escaping overhead; agent calls kleinanzeigen_search directly.
  • Automatic storage: SQLite database path automatically resolves inside $HERMES_HOME/plugin-data/.
Secondary / Fallback

Standalone Hermes Skill

For restricted environments where the plugin manager is disabled. The agent interacts with Python scripts via shell execution in terminal.

Skill Installation 
$ hermes skills install clockwork-dev/hermes-kleinanzeigen/kleinanzeigen
Manual Dependency Provisioning 
$ hermes pm environment --add "requests>=2.31.0" "beautifulsoup4>=4.12.0" "fake-useragent>=1.5.0"
  • Requires manual dependency installation into Hermes Python environment.
  • Agent invokes skills/kleinanzeigen/scripts/search_cli.py via terminal command.
  • Useful when running in restricted minimal environments.

Technical Architecture

Engineered for lightweight agent execution with resilient fallback mechanisms.

01

Canonical URL Generation

Constructs deterministic paths matching Kleinanzeigen routing rules: /s-preis:{min}:{max}/s-seite:{page}?keywords={query}&locationStr={plz}&radius={radius}. Supports German umlaut transliteration and radius filtering.

02

Dual-Engine Fetcher

Executes HTTP-first requests using desktop Chrome/Edge user-agents. If Akamai or IP-range blocks return HTTP 403, the engine falls back to headless Playwright with aggressive subresource blocking (images, fonts, stylesheets) for speed.

03

Hybrid Astro / SSR Parser

Extracts listings from modern Astro SSR hydration markers (<astro-island>, topAd flags, [data-image-container]) and classic BEM card classes. Excludes paid promotion tiles when requested.

04

SQLite Deduplication

Maintains query states using SHA-256 hashes in a local SQLite table (seen_ads). Cron monitoring polls intervals without emitting duplicate alerts, outputting Telegram Markdown or JSON.

Tool & Script Reference

Available tools in the Hermes runtime.

Tool / Script Type Parameters Output
kleinanzeigen_search Plugin Tool query, postal_code, radius, min_price, max_price, limit, exclude_topads, fetch_mode Structured JSON object with success, total_found, ads array (id, title, price, location, url, image_url, shipping, description).
kleinanzeigen_monitor Plugin Tool Same as search plus db_path, format (telegram or json), mark_seen (boolean). Returns only previously unseen listings. Tracks state in SQLite database.
search_cli.py CLI Script query [args...] (--plz, --radius, --min-price, --max-price, --limit, --browser) JSON array to stdout for scripting and shell parsing.
monitor.py CLI Script query [args...] (--db, --telegram, --format json, --dry-run) Standard output formatted as JSON or copy-paste Telegram Markdown alerts.
⚠ Anti-Bot Protection & Ethical Scraping Policy

This tool strictly adheres to honest scraping ethics. It does not attempt to bypass, crack, or solve CAPTCHAs, Cloudflare Turnstile, or anti-bot verification gates. When an anti-bot challenge is encountered, the fetcher raises an explicit KleinanzeigenBlockedError with clear diagnostic feedback. Sequential page crawling includes respectful delays.
